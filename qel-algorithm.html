1
Primitives

Transform one interval ensemble

Four primitives, each ending in normalization.

Pseudocode 
function DISPLACEMENT(δ, q)
  subtract q from every finite boundary
  preserve closure marks
  return NORMALIZE(δ)

function DILATION(δ, r)
  for each interval endpoint pair
    subtract r from the left endpoint
    set that closure mark to 0
  return NORMALIZE(δ)

function EROSION(δ, r)
  for each interval endpoint pair
    subtract r from the right endpoint
    set that closure mark to 1
  return NORMALIZE(δ)

function COMPLEMENT(δ)
  add the missing exterior endpoints
  flip open and closed marks
  return NORMALIZE(δ)

Normalization removes empty intervals and merges overlapping or adjacent compatible intervals.

Model check

Translate, substitute, eliminate, evaluate

One record and one candidate, from formula to decision.

Pseudocode 
function MODELCHECK(ε, φ, q)
  Φ(y) ← TRANSLATETODOAG(ε, φ, y)
  Φ_q  ← Φ(q)
  Ψ    ← QE_DOAG(Φ_q)
  return EVALUATELINEARBOOLEANFORMULA(Ψ)

◊ and □ introduce existential and universal auxiliary variables over [y, y+t); QE removes them.

Finite evidence

Restrict finite evidence to observed points

Only boundaries already present in the record become observation points.

Pseudocode 
function FINITEEVIDENCE(ε, φ[x], q)
  Φ(x) ← TRANSLATETODOAG(ε, φ[x], q)
  Ψ(x) ← QE_DOAG(Φ(x))
  H    ← all affine boundary hyperplanes
         occurring in Ψ
  cells ← finite sign-cell decomposition
          of ℚⁿ induced by H
  F    ← one rational point from each
         nonempty sign cell
  return F

The four points are x, x+a, x+a+b, and x+a+b+c. The demo restricts each to an existing BEST boundary; no midpoints or ε-shifts.
