One evaluation set, two query formulas

PGES base is the permissive reference query: it asks for a T and a C occurrence in their windows, so intervals may overlap or extend outside S, and P may begin before the offset. PGES strict is one exact formula with a 10 s no-event prefix, S∧¬P, T∧¬C, C∧¬T, and P∧¬S. The exclusions sit inside the formula, so a boundary meet is allowed and postictal T/C is not excluded because the last conjunct only excludes S.

Interval-ensemble semantics

Each label is a finite union of closed intervals. Displacement, ◊, and □ are implemented as endpoint translation, future-window dilation, and future-window erosion; conjunction is intersection.

Finite witnesses, not sampling

The presets use interval boundaries from each case to find and verify witnesses. Custom formulas derive time variables from all case endpoints and their differences, then check the edited expression with the same interval semantics. Use the Solver selector to compare the preset search paths. See the step-by-step algorithm trace →

Two formulas, one evaluation set

Both formulas run on the same cases. Base PGES is deliberately permissive: it does not force T and C intervals to be disjoint, contained, or before the offset, and P may start earlier. Strict PGES uses the exact formula ∃x∃a∃b∃c [□10∅ ∧ (□a+b(S∧¬P))10 ∧ (◊a(T∧¬C))10 ∧ (◊b(C∧¬T))10+a ∧ (□c(P∧¬S))10+a+b]x. T/C overlap is allowed when each exclusion has a witness, postictal T/C is allowed because the last conjunct excludes S, not T or C, and c may end before P does. The comparison strip keeps both counts visible.
