1 · Representation

BEST: one record, one interval-ensemble function

A BEST turns time-stamped clinical annotations into a finite semantic object that QEL can check.

Interval

An interval on ℚ

An interval is a set of rational time points between two endpoints. Endpoints may be open or closed; a singleton is a closed interval [q, q].

[(s, t)] = { q ∈ ℚ | s ⪯ q ≪ t }

Interval ensemble

A finite, non-overlapping set

An interval ensemble δ is a finite set of non-overlapping intervals. It may be empty, and it may contain several disjoint episodes of the same clinical event.

δ = { [10, 70], [120, 160] }

BEST

A label-to-ensemble function

A BEST ε maps every atomic label p to an interval ensemble ε(p). Labels that map to the empty ensemble are omitted from the graph.

Storage

Boundary arrays and closure marks

The paper represents a canonical interval ensemble by two parallel arrays. For example, the ensemble δ₂ = {(1,2), [3,4), [41/10, 26/5], {13/2}} is stored as:

# boundary time points
boundary     = [1, 2, 3, 4, 41/10, 26/5, 13/2, 13/2]
# 0 = open, 1 = closed
closure_mark = [0, 0, 1, 0, 1, 1, 1, 1]

Every primitive operation is a pass over these arrays followed by normalization: remove empty intervals and merge overlapping or adjacent compatible intervals.

!
Why this representation matters for reproducibility The semantics never depends on a particular database schema. Once annotations are expressed as interval ensembles, the same QEL formula can be checked by the backend, by a notebook, or by the static browser demo on this site.
2 · Query construction

QEL: write the phenotype as a formula

QEL keeps a small operator vocabulary: displacement, bounded existence, bounded universality, Boolean connectives, and first-order quantification over rational time.

Syntax

The full language

φ, ψ ::= p
        | ¬φ
        | φ ∧ ψ
        | φu              // displacement
        | ◊t φ            // bounded existence
        | □t φ            // bounded universality
        | ∃x φ  |  ∀x φ      // point variables

Here p is an atomic label, u is a point term, and t is a positive norm term. In this paper the index domain is ℚ and the future direction is used.

Semantics

Truth at a rational point r

r ⊨ pr lies in the support of label p
r ⊨ φu(r + u) ⊨ φ
r ⊨ ◊t φsome s ∈ [r, r+t) satisfies φ
r ⊨ □t φevery s ∈ [r, r+t) satisfies φ

The window is half-open. This is why dilation opens the new left boundary and erosion closes the new right boundary.

Displacement

“Immediately after”

φu moves the evaluation point by u. The PGES conjunct (□cP)a+b is the mechanism that anchors suppression to the end of the chosen seizure block.

Bounded existence

“Somewhere within”

◊tφ says that φ occurs at least once in the next t time units. It is implemented as future-window dilation of the support of φ.

Bounded universality

“Throughout”

□tφ says that φ holds at every point in the next t time units. It is implemented as future-window erosion of the support of φ.

Build recipe

How to turn a clinical sentence into QEL

Choose the event labels

Name the annotated events that carry the phenotype, e.g. S, T, C, P.

Write persistence with □

“S lasts for a + b” becomes □a+bS.

Write bounded occurrence with ◊

“T occurs within the first a” becomes ◊aT.

Anchor the next phase with displacement

“After a, C occurs within b” becomes (◊bC)a.

Quantify the anchors and durations

Close the formula with ∃x ∃a ∃b ∃c. The cohort is the set of records for which a witness exists.

Support algebra

From formula structure to interval operations

For a fixed BEST ε and assignment to free variables, the support [[φ]]ε is again an interval ensemble. The recursive rules are:

FormulaSupport operation
atomic pε(p)
φudisplacement by u
◊tφdilation by t
□tφerosion by t
φ ∧ ψintersection
φ ∨ ψunion
¬φcomplement

A record satisfies a quantifier-free formula at q exactly when q belongs to its support.

↳
Why the PGES formula has four quantifiers x chooses the seizure anchor, a chooses how much of the seizure is the tonic window, b chooses the remaining clonic window, and c chooses the suppression duration. The logical statement is existential: a patient is included if at least one consistent choice exists.
3 · Database to cohort

Evaluate the formula record by record

The cohort is defined by logical satisfaction, not by a hand-written procedural heuristic.

Definition

The PGES cohort

[[ψ]]D = { ε | (ε, q) ⊨ ψ, ε ∈ D }

D is the database of BEST records. The formula is checked independently for each record ε. In the PGES search, the existential block ranges over seizure anchors and duration variables; a record is included if some witness satisfies the whole body.

Step 01

Load annotations

Convert a recording session into a BEST: one interval ensemble per clinical label.

Step 02

Compile the formula

Translate displacement, ◊, □, and Boolean operators into interval transformations.

Step 03

Evaluate supports

Compute the interval ensemble for the quantifier-free body under a candidate assignment.

Step 04

Find finite witnesses

Use endpoints, constants, and boundary-derived representatives instead of searching dense ℚ.

Step 05

Project the cohort

Include the record if a witness makes the body true; aggregate patients and matched patterns.

Finite evidence

Why dense time does not require dense search

The paper proves that, after fixing a BEST, a reference point, and a QEL formula, the satisfying assignments of the free rational variables form a finite union of polyhedral cells. The truth value is constant on each cell and on each bounding face.

Therefore a finite test set F can be chosen from the arrangement induced by the formula's linear inequalities. For one variable this reduces to endpoints, rational midpoints between consecutive endpoints, and two exterior samples.

endpoints of ε rational constants in ψ reference point q one witness per cell
Complexity

Record-local endpoint-array model checking

Let N be the total number of interval boundaries in a record and let |ψ| be the syntax-tree size. For a formula whose finite-evidence enumeration uses at most k free rational variables in any quantified block, the paper gives the bound:

O(|ψ| · Nk+1)

For every fixed formula the data complexity is polynomial. The PGES formula has a small, fixed number of quantifiers, so the expensive part in practice is the number of interval boundaries and the number of matching patterns.

Aggregation outline

How the backend compiles a temporal condition

// eeg_query_api.rs — construct_query
$match   { e: { $in: event_ids } }
$project { subjectid, e, times }
$unwind  "$times"
$group   { _id: "$subjectid", ... }
$project { e1: { $setDifference: [...] }, ... }
$match   { $expr: { $and: [...] } }
$unwind  "$e1"; $unwind "$e2"
$project { min_e1, max_e1, min_e2, max_e2, ... }
$addFields { tel_cond: ... }
$match   { tel_cond: true }
$group   { _id: { subjectid, ... } }

The pipeline first groups annotation timestamps by patient and event, then compiles the temporal condition into tel_cond, and finally keeps the patients for which the condition evaluates to true.

!
Index path versus model-checking path Binary relative-temporal queries can use the precomputed telii index in query_api.rs. The PGES case exercises the richer timeline path: extract per-patient event arrays, build min/max boundaries, evaluate the compound support condition, and return subject-level matches. The static playground mirrors the second path in the browser.
4 · PGES cohort query

The paper's PGES run, audited

Generalized EEG suppression: a GTC seizure followed by continuous suppression immediately after seizure offset.

Clinical specification

What PGES adds to GTC

A generalized tonic–clonic seizure is specified by a continuous seizure block S, a tonic phase T in its first part, and a clonic phase C after displacement by a. PGES adds one conjunct: after the seizure offset, suppression P must persist for c.

ψPGES = ∃x∃a∃b∃c [ □a+bS ∧ ◊aT ∧ (◊bC)a ∧ (□cP)a+b ] x

The displacement (·)a+b is what enforces the postictal ordering: the suppression window is anchored to the end of the chosen seizure block, not to an arbitrary later time.

For example, eroding S = [10,70] by a+b = 60 gives the singleton [10,10]; dilation of T = [10,30] by 22 gives (-12,30]; and dilating C = [32,68] by 38 then shifting by 22 gives (-28,46]. All four supports contain x = 10.

Witness selection

Why these numbers are legitimate

a = 22 s

The clonic phase starts at 32 s. Setting x + a = 32 makes the tonic window [10, 32); T = [10,30] lies inside it.

b = 38 s

The seizure ends at 70 s, so a + b = 60 and x + a + b = 70. This maximizes the continuous S block and anchors P at seizure offset.

c = 45 s

P = [70,115] is active for exactly 45 s after the offset. The box condition holds on [70,115).

Reading the result

Patients and patterns are different counts

A patient is included once, but can contribute more than one matched annotation pattern. The paper reports 37 patients and 45 patterns, so some records contain multiple qualifying seizure/suppression configurations.

The interface in Figure 3 returns the patient list and visualizes each matched pattern on a time-aligned axis. This is the same distinction the playground makes when it counts matched patients separately from matched patterns.

Reproducibility boundary

What these numbers do and do not certify

They certify the paper's end-to-end workflow on its clinical database. They do not certify the static demo, which uses 54 synthetic records. The demo is intended to make the semantics inspectable and executable, not to reproduce the clinical cohort or its runtime.

The paper itself describes the 15.97 s result as an illustrative feasibility result rather than a systems benchmark. Query planning, indexing, and comparison with hand-written database queries are left to a companion study.
